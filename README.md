Welcome to **Fusion Mart 2.0**, a modern e-commerce website designed to make online shopping simple and convenient. Browse products across multiple categories, search for your favorite items, and add products to your shopping cart.

🔗 **GitHub Repository:** [Fusion Mart 2.0](https://github.com/sudhanshuv837-stack/fusion-mart-2.O)

## 📌 About the Project

Fusion Mart 2.0 is a front-end e-commerce website project that provides a simple and user-friendly online shopping experience. It features a collection of electronic products, including smartphones, laptops, smartwatches, audio devices, and accessories.

The project is built to practice web development skills and demonstrate the basic functionality of an online shopping website.

## ✨ Features

- 🏠 **Home Page** – A simple and attractive shopping interface.
- 📱 **Product Categories** – Browse mobiles, laptops, watches, audio devices, and accessories.
- 🔍 **Product Search** – Find products quickly using the search bar.
- 🗂️ **Category Filtering** – Filter products by category.
- 🛍️ **Shopping Cart** – Add products to your cart.
- 💰 **Product Prices** – View product prices in Indian Rupees (₹).
- 🧾 **Checkout Button** – Access the checkout option from the cart.
- 🎨 **Clean User Interface** – Easy-to-use product cards and navigation.

## 🛠️ Technologies Used

- **HTML5** – Website structure.
- **CSS3** – Styling and layout.
- **JavaScript** – Product filtering, search, and shopping cart functionality.

## 🚀 Getting Started

Follow these steps to run Fusion Mart 2.0 on your computer.

### 1. Clone the Repository

Open your terminal and run:

```bash
git clone https://github.com/sudhanshuv837-stack/fusion-mart-2.O.git
```

### 2. Open the Project Folder

```bash
cd fusion-mart-2.O
```

### 3. Run the Website

- Open the project folder in Visual Studio Code.
- Open `index.html` in your browser, or use the **Live Server** extension in VS Code.
- Start exploring the products and shopping cart.
